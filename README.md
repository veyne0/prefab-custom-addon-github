# Prefab Custom Addon

Prefab 模组的扩展。

> **关于开发**
> 本模组的代码由 AI 编程工具（TRAE）生成，作者本人 Java 学习时间不长，没有能力自己写模组。如果遇到 bug 或有功能建议，欢迎在 Issue 反馈。

## 功能

- 游戏内建筑包浏览器（Z）
- 游戏内建筑包制作器（X）
- 支持社区建筑包格式
- 兼容原版 Prefab 模组

## 运行环境

- Minecraft 1.21.1（NeoForge）或 1.20.1（Forge）
- 需要安装 Prefab 原版模组
- 需要安装 LDLib2

## 安装

放入 `mods` 文件夹即可。。
